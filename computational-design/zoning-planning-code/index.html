Practical practice Rules

The rules, including green design, that shape feasible work — encoded before form is finalized.

Rules are the first design layer

Zoning districts, planning overlays, and building codes define what can be built before a single line is drawn. Practical practice means those rules enter the computational model as measurable constraints — setbacks, FAR, height planes, egress paths, and energy targets — not as after-the-fact corrections.

When rules are modeled early, design options are compared inside the feasible envelope. Options that violate code or green-design thresholds are caught in iteration, not at permit submission.

Zoning, planning, and code as parameters

  • Zoning — lot coverage, use types, parking ratios, and open-space requirements set the buildable volume.
  • Planning — design review criteria, historic overlays, and greenbelt buffers shape massing and landscape sequence.
  • Code — structural, fire, accessibility, and MEP provisions define minimum dimensions and system capacities.

Green design inside the rule set

Green-building standards — daylight access, ventilation, rainwater capture, envelope performance — are treated as design drivers, not checklist items at the end. North Fork–style ranch studies, Calla Lily–style passive systems, and closed-loop concepts all start from environmental rules that the geometry must satisfy.

Parametric models make those requirements visible: when a shading angle, tank volume, or roof slope changes, the compliance assumption updates with it. The team sees the trade-off between form and performance in real time.

Feasible work, documented and defensible

Practical practice rules produce projects that can move through planning review, permitting, and construction without rework. Assumptions are versioned: which code edition, which zoning map, which green standard — all recorded alongside the model.

That documentation is what separates computational novelty from professional practice. The rules are not hidden inside a script; they are stated, checked, and handed off with the drawings.
